# Still · 專注當下

Tauri 2 + TypeScript + Vite 製作的繁體中文、離線優先番茄鐘。無帳號、無追蹤、無遠端字型或音訊依賴。

## 啟動

```sh
npm ci
npm run dev          # 瀏覽器預覽 http://127.0.0.1:1420
npm test             # 計時核心測試
npm run build        # TypeScript 檢查與正式前端建置
npm run tauri dev    # 桌面開發模式
npm run tauri build  # 在目前平台產生安裝檔
```

Node.js 建議 22.12+。桌面版另需 [Tauri 平台先決條件](https://v2.tauri.app/start/prerequisites/)：Rust stable；Windows 需要 Visual Studio C++ Build Tools 與 WebView2；macOS 需要 Xcode Command Line Tools。

`.github/workflows/build.yml` 提供手動及 `v*` tag 觸發的 Windows x64、macOS Apple Silicon／Intel 建置，输出 workflow artifacts，不自動發布。正式散布前須配置開發者簽章與 macOS notarization。本次環境沒有 Rust，原生編譯、安裝檔與 CI 尚未驗證。

## 功能

- 專注、短休息、長休息；預設 25／5／15 分鐘，每 4 個完成回合長休息。
- 開始、暫停、繼續、重設、跳過；自訂時間、長休息間隔、自動開始休息／專注。
- 截止時間倒數；重新開啟恢復計時。休眠恢復最多結算一個進行中的回合，不補算不存在的專注。
- 任務新增、編輯、完成、還原、刪除；專案、優先度、到期日、備註、預估番茄數、實際完成數。
- 任務搜尋／狀態篩選、任務範本、剩餘工作時間估算。
- 任務歸屬鎖定於回合開始；中途選擇其他任務從下一回合生效。
- 今日進度、每日目標、7／30／365 天統計、專案分配、歷史紀錄、CSV 匯出。
- 深色、淺色、跟隨系統；精簡模式；桌面視窗置頂。
  - 精簡模式為 280 × 160 邏輯像素的無標題列小浮窗，顯示倒數、任務、回合、進度與開始／暫停按鈕。
  - 拖曳浮窗頂部移動，圖釘切換最上層，展開按鈕或 Esc 恢復原本視窗大小；切換不會中斷計時。
  - 瀏覽器預覽只顯示浮窗介面；移動桌面視窗、置頂及原生尺寸需在 Tauri 桌面版驗證。
- 兩種提示音、音量、合成背景噪音、系統通知（需授權）、休息健康提示。
- 分心次數記錄、視窗內快捷鍵 Space／R／Esc。
- 本機保存、JSON 備份還原；桌面原生檔案選擇器，瀏覽器使用下載／上傳。
- 輸入驗證、HTML escaping、CSV 公式注入防護、受限 Tauri capabilities。

### 已知行為

- 關閉視窗會結束程式；程式關閉或休眠期間不會準時推播，重開／喚醒後補結算目前回合。
- Windows 通知需要安裝版驗證，系統設定可能阻擋提醒。
- 資料存在 WebView localStorage；移除應用程式資料會清除紀錄，請使用 JSON 備份搬移。瀏覽器預覽與桌面版資料獨立。
- 歷史列表顯示期間最新 100 筆，統計使用期間全部紀錄，CSV 匯出全部歷史。
- 背景音為本機產生的低頻噪音；調整音量後重新開啟背景音生效。

## 結構與驗證

`src/model.ts` 為計時／備份核心，`src/main.ts` 包含介面與平台 API，`src/style.css` 為主題樣式，`src-tauri/` 包含 Rust 入口、權限與打包設定。

TypeScript + Vite 正式建置與核心測試已通過；原生功能須以平台建置與實機結果為準。
